# AniPlay для Lampa

Самостоятельный репозиторий: плагин Lampa + сервер Node.js без сторонних npm-зависимостей. Сайт AniPlay и Android-приложение продолжают работать отдельно.

## Установка на Render

[Развернуть на Render](https://render.com/deploy?repo=https://github.com/lacost2001/aniplay-lampa)

1. Создайте сервис из `render.yaml` (Blueprint) или Web Service из этого репозитория.
2. Runtime: Node. Build: `npm ci && npm test`. Start: `npm start`. План: Free.
3. Задайте `TMDB_API_KEY` — API key каталога TMDb. Firebase и токен Telegram не нужны.
4. После успешного запуска откройте адрес сервиса. Страница покажет точную ссылку на плагин: `https://АДРЕС-СЕРВИСА/aniplay.js`.
5. Lampa → Настройки → Расширения → Добавить плагин → вставьте ссылку → перезапустите Lampa.
6. Откройте контекстное меню карточки TMDb (удержание ОК), выберите **Смотреть через AniPlay**.

Сервер и плагин размещаются вместе: адрес сервера определяется по ссылке подключения. При необходимости его можно изменить в Настройки → AniPlay. На бесплатном Render возможен холодный запуск: повторите запрос после пробуждения сервиса. Самопинги не используются.

## Что работает

- Фильмы и сериалы из карточек TMDb; выбор реальных сезонов и серий.
- Источники из двух зеркал DDBB; одинаковые ссылки объединяются.
- Collaps и Veoveo через парсеры AniPlay, а также прямые видеоссылки фильмов.
- Alloha, Turbo и другие iframe-источники открываются в отдельном внешнем плеере. Прогресс, переключения серий и озвучки внутри iframe не синхронизируются с Lampa; на части ТВ такие плееры могут быть несовместимы.
- Встроенный плеер Lampa, возврат кнопкой «Назад», отмена загрузки.
- Отдельная локальная история AniPlay в боковом меню.
- Продолжение с последнего источника и позиции; сохранение раз в минуту и при закрытии плеера.
- Отметка просмотра после 65%; отдельные записи по категориям `movie:ID` и `tv:ID`.
- Если прямой поток точной серии отсутствует, открывается внешний плеер с параметрами сезона и серии. Внешний источник может проигнорировать эти параметры — проверьте выбранную серию в его интерфейсе.

## Границы версии 1.1

Привязка аккаунта AniPlay, облачная синхронизация с Firebase, импорт библиотеки сайта, каталог AniLiberty, манга и автоматический переход к следующей серии **не реализованы**. Это самостоятельный плагин просмотра фильмов и сериалов, а не копия всего сайта. История хранится на устройстве Lampa. Внешние Android-плееры могут не передавать прогресс обратно; продолжение проверяйте со встроенным плеером.

Доступность провайдеров зависит от региона и сторонних серверов. Некоторые CDN требуют IP/Referer источника: такие потоки могут не воспроизводиться на ТВ даже при успешном извлечении ссылки. Сервер не ретранслирует видео и не обходит DRM. Совместимость на конкретном телевизоре требует проверки; автоматические тесты используют имитации провайдеров.

## Локальный запуск

Node.js 22+. Скопируйте `.env.example` в `.env`, заполните `TMDB_API_KEY`.

```sh
npm ci
npm test
npm start
```

Откройте `http://localhost:3000`. На телевизоре вместо localhost укажите LAN-адрес компьютера. Для публичного подключения используйте HTTPS.

## API и безопасность

- `/health`: версия и наличие конфигурации.
- `/api/details?id=1622&type=tv`: сезоны.
- `/api/sources?id=1622&type=tv`: доступные источники и признак поддержки.
- `/api/resolve?id=1622&type=tv&season=2&episode=20&source=...`: прямая ссылка выбранной серии.

API не принимает произвольные URL для загрузки. Список серверных хостов ограничен; редиректы разрешены только внутри того же origin, не более трёх; ответы ограничены 4 MiB и тайм-аутом. Кэш источников ограничен 100 тайтлами и двумя минутами. API публичный, без авторизации; для большой аудитории нужны ограничения запросов на хостинге. Не добавляйте ключи Firebase Admin или другие привилегированные секреты в плагин.

Парсеры `lib/` перенесены из проекта AniPlay. Документация API Lampa: https://github.com/yumata/lampa-source/tree/main/docs/en.

## Проверка перед выпуском

`npm test` проверяет разные категории одного ID, точный выбор серии, запрет произвольных серверных URL, ответы API, однократную регистрацию плагина. На реальном устройстве: установить по HTTPS, открыть фильм/сериал, проверить Back, источники, 2×20, закрытие/возобновление, недоступный источник. Для обновления публикуйте изменения в main, дождитесь автодеплоя Render и перезапустите Lampa.
